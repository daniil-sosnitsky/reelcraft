# Reelcraft — конвейер вертикальных роликов на Remotion

Запись голоса на входе → готовый вертикальный ролик 1080×1920 на выходе:
пословные караоке-субтитры, живые скриншоты с наездом камеры, монтаж по
каталогу приёмов, звуковые эффекты, музыка с дакингом под речь, финальная
CTA-карточка канала.

Ролик собирает не человек, а агент (Claude Code) — по правилам, которые лежат
прямо в репозитории. Человек записывает голос и принимает результат.

Этим конвейером собрано больше тридцати роликов. Что в нём работает, где он
ломался и чего стоило поднять его нативно на Windows — описано внутри, вместе
с граблями.

## Установка — одной командой агенту

```
Установи конвейер по инструкции INSTALL.md в этом репозитории.
```

Агент дальше работает сам: проверит систему, поставит распознавание речи,
принесёт каталог приёмов, соберёт движок, спросит данные твоего канала и
сделает контрольный рендер. **40–90 минут**, в основном — скачивания.
Нужно около 6 ГБ места на диске и интернет.

Полная инструкция, со всеми проверками и разбором поломок: **[INSTALL.md](INSTALL.md)**.

### Где это работает

| Платформа | Статус |
|---|---|
| **macOS** | ✅ работает |
| **Linux** | ✅ работает; нет забора записей из Диктофона и `caffeinate` |
| **Windows 10/11** | ✅ работает **нативно**, через Git Bash — WSL не нужен |
| **iPhone / iPad** | ❌ не ставится |

**Про iPhone честно.** Конвейеру нужны Node.js, ffmpeg, Python, whisper.cpp и
headless-браузер для рендера — на iOS не запускается ни одно из этого. Телефон
в этой схеме полезен иначе: пишешь на него голос и кидаешь файл в `inbox/`, а
готовый ролик забираешь оттуда же в TikTok, Reels и Shorts.

**Про Windows.** WSL не нужен и даже вреден: правило 27 требует живого экрана в
кадре, а из WSL скриншоты окон Windows не снять. Инструментарий (ffmpeg,
whisper, модель распознавания) ставится внутрь проекта в `tools/` одной
командой — `tools/restore-tools.ps1`. Почему так и какие поломки по дороге
чинятся — [tools/WINDOWS.md](tools/WINDOWS.md).

## Как это работает

```
запись голоса → prep.sh (нормализация −14 LUFS, ускорение ×1.2)
              → queue-add.sh (whisper: пословный транскрипт)
              → сториборд (агент: биты речи + приёмы из каталога)
              → вёрстка сцен (Remotion / React)
              → линт сцен + авто-QA по контактному листу
              → рендер + мастеринг звука → MP4
```

Правила намеренно жёсткие: минимальная жизнь элемента в кадре, одна точка
внимания, обязательный живой экран, заполненная вертикаль, неприкосновенная
полоса субтитров. Они и делают ролик смотрибельным без ручного монтажа.

**Про темп — чтобы не было разочарования.** Ролик собирается штучно: под
каждый сценарий верстается 8–12 сцен, творческая часть идёт на основной модели.
Реалистично 4–8 роликов в месяц, а не 30 за вечер. Первый ролик занял три часа,
и час из них ушёл на разбор брака: падал рендер, видеоряд уехал на бит
относительно речи, оставались пустые кадры. Правила и автопроверки с тех пор
дописаны ровно по этим граблям и лежат внутри.

### Три скилла, не один

| Скилл | Что делает |
|---|---|
| `reelcraft` | Собирает ролик: транскрипт → сториборд → сцены → QA → рендер |
| `reels-radar` | Ищет темы: парсит ролики аккаунтов-доноров, считает выброс по медиане, отдаёт шортлист тем с разбором хука. **Конвейера не требует** — работает сам по себе |
| `profile` | Берёт у тебя интервью и собирает профиль: как ты говоришь, что считаешь важным. Из него конвейер пишет сценарий **твоим** голосом, а не средним |

Радар отвечает на вопрос «о чём снимать», конвейер — «как собрать». Метрика
радара: кандидат проходит, только если обошёл **и** свою медиану (≥3×), **и**
абсолютный порог просмотров. Одного коэффициента мало — у спящего аккаунта
медиана может быть 500, и ролик на 1700 даст «выброс 3,4×», хотя тема себя
ничем не проявила. Разбор — [radar/README.md](radar/README.md).

## Чего в комплекте нет и почему

| Чего нет | Почему | Что делать |
|---|---|---|
| Звуковые эффекты (mp3) | Берутся из первоисточника — каталога приёмов | `scripts/setup-assets.sh`, шаг 5 установки |
| Музыка | Лицензия разрешает использовать треки в роликах, но запрещает перевыкладывать файлы | скачать с mixkit.co, шаг 5 |
| Модель распознавания речи | 1,5 ГБ | шаг 2 (Windows: `restore-tools.ps1`) |
| Каталог приёмов | Отдельный открытый репозиторий | шаг 3 |
| ffmpeg и whisper под Windows | GitHub не принимает файлы больше 100 МБ | `tools/restore-tools.ps1` |
| Персонаж светлой темы | Едут нейтральные серые заглушки: движок с ними запускается, но в ролик такое не выпустишь. Персонаж — это ты, его рисует нейросеть по готовому промпту, и агент на этом шаге помогает | шаг 8; требования — `engine/public/shared/character/README.md`, промпт — `library/character-prompt.md` |
| Аккаунты-доноры для радара | Чужие доноры дадут чужие темы. В комплекте только примеры формата | шаг 9а, разбор — `radar/README.md` |
| Аватар и скрин канала для CTA-карточки | Личные файлы — подставляешь свои | шаг 7 |
| Готовые ролики и банк футажа | Личный контент | не нужны: образец кода — `engine/src/videos/demo/` |

Код и правила конвейера — свободно для личного и коммерческого использования,
без гарантий. Полный разбор по каждому материалу — [LICENSES.md](LICENSES.md),
полные тексты — в [`licenses/`](licenses/).

Два момента, которые стоит знать заранее:

- **Remotion** бесплатен для физических лиц, некоммерческих проектов и компаний
  до 3 человек включительно — в том числе для монетизируемых роликов на YouTube,
  Reels и TikTok. **Компаниям от 4 человек нужна платная лицензия.**
- **Каталог приёмов** — проект
  [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) под
  Apache License 2.0. Что именно из него заимствовано и что изменено — в
  [NOTICE](NOTICE), как того требует раздел 4(b) этой лицензии.

Добавляешь что-то своё — пиши строку в соответствующий INDEX с источником и
лицензией **до того**, как файл попадёт в git. И проверяй два вопроса отдельно:

сам файл. Ответы часто не совпадают.
