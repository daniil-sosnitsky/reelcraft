# Опись банков (шаг 4а)

Механическая сводка «что есть в банках под этот нарратив». Отбор футажа сюда
**не входит** — он на `reel-footage` (Opus), потому что требует смысловой
сверки клипа с речью. Запускается **параллельно** с `reel-transcript`.

## Что описать — шесть банков

| Банк | Источник правды |
|---|---|
| Иконки брендов | `engine/public/shared/icons/manifest.json` |
| Общие пиктограммы | `engine/public/shared/icons/generic/` (Lucide, ~2000 SVG) |
| Lottie | `engine/public/shared/lottie/INDEX.md` |
| Персонаж и стикеры | `engine/public/shared/stickers/`, `character/` |
| Компоненты shotcraft | `library/components.md` + `engine/src/lib/` |
| SFX | `engine/public/shared/sfx/CATALOG.md` + `NOTES.md` (стоп-лист) |
| BGM | `engine/public/shared/bgm/INDEX.md` |

Плюс анти-повтор: **две последние строки** `library/used-log.md` (хук, приёмы,
BGM) и сториборды активных слотов `queue/video-*/storyboard.md` — used-log
отстаёт от параллельных сессий.

## Правила

- **Недостающие иконки докачать сразу:** `node scripts/fetch-icons.mjs <бренды>`
  — все бренды нарратива до вёрстки, не после.
- Логотип чужого бренда вместо понятия ставить нельзя: для понятий
  (субтитры, монтаж, папка, часы) — `icons/generic/<имя>`.
- SFX из стоп-листа (`sfx/NOTES.md`, вся папка `riser/`,
  `ui/switch-click-quick`, `data/power-up-electronic`, `camera/zoom-air-fast`)
  не предлагать вообще: запрет по тембру, тише ставить нельзя.
- У каждого SFX считать `volume` по формуле из `CLAUDE.md` («Звук») с пиком
  из `CATALOG.md` — не на глаз.
- BGM не должен повторять трек прошлого ролика.
- Lottie — только там, где иконка герой момента; в перечислениях статичный SVG.

## Выход

Таблица по каждому банку: **что взято / отказ с причиной**. Без строк «в
принципе можно» — либо конкретный файл с путём, либо отказ. Режиссёр вставит
сводку в сториборд как секцию «Ассеты из банков»; без неё сториборд не готов.

## Бюджет контекста

- **Аварийный тормоз: 40 вызовов инструментов за прогон.** Это не рабочая
  норма (нормальный прогон — 14–25 вызовов, замер 2026-10-17), а
  предохранитель от разгона. Дошёл до тормоза — **остановись и отдай отчёт с
  перечнем неописанных банков**, не крутись дальше.
- Манифесты и каталоги читать `grep`/`sed -n` по нужному, а не целиком: один
  файл не читается целиком дважды.
