# out/ — рендеры и артефакты проверки

Рабочая папка вывода: черновые рендеры, кадры, контактные листы QA. Всё здесь
**пересобирается** — папку можно чистить целиком (`scripts/clean-out.sh`).

| Что | Откуда |
|---|---|
| отдельные кадры (`*.png`) | проверка композиции до полного рендера |
| `frames/` | раскадровка собранного ролика |
| `full/` | полные рендеры |
| `chk*/` | проверочные прогоны отдельных сцен |

## Готовые ролики здесь не хранятся

Сданный ролик уезжает в папку вывода, которую ты указал при установке
(`engine/src/channel.ts`), и она держится **вне репозитория**: 10–30 МБ на
ролик, в git им делать нечего.

## В git не уходит

Ни рендеры, ни кадры: это артефакты, а не исходники. Исходник ролика — сцены
в `engine/src/videos/` и слот в `queue/`. В репозитории живёт только эта
подпись.
