# cta/ — финальная карточка канала

Последние секунды ролика: аватар канала, имя, хендл, слоган и кнопка подписки.
Карточка собирается из данных `engine/src/channel.ts` и двух картинок, которые
ты кладёшь сюда сам.

| Файл | Что это | Есть в комплекте |
|---|---|---|
| `telegram-round.svg` | иконка Telegram, двухцветная | ✅ да |
| `avatar.png` | **твой** аватар канала, PNG с альфой, обрезанный по кругу | ❌ положи свой |
| `tg-channel.jpg` | **твой** скрин шапки канала — запасной пруф | ❌ положи свой |

Аватара и скрина в комплекте нет намеренно: это личные файлы конкретного
канала, и в чужом ролике они не нужны.

## Как подготовить аватар

Обрезать по кругу **заранее**, в редакторе, и сохранить PNG с прозрачностью.
Если положить квадратную картинку, в кадре будет квадрат с чужим фоном —
карточка сразу выглядит собранной на скорую руку.

## Как подготовить скрин шапки

Telegram Desktop на весь экран: видно аватар, название и описание, без
админского меню в кадре. После этого **померь пропорции файла и впиши их
в `ctaProofAspect`** (высота/ширина) в `channel.ts` — иначе картинка
растянется.

## Два режима пруфа

| Режим | Что показывает | Когда брать |
|---|---|---|
| `profile` | аватар + имя канала, рисуется нативно | по умолчанию: не мылит ни при каком масштабе |
| `image` | скрин шапки картинкой | когда нужно показать именно шапку как она есть |
| `stats` | аватар + число подписчиков | только когда цифра начала продавать |

Про счётчик подписчиков: оставлять его пустым, пока число маленькое, — это
решение, а не недоделка. Маленькая цифра в кадре работает против канала, а
выдумывать её запрещает правило 17. Ориентир, с которого пруф начинает
помогать, — несколько сотен подписчиков.

## Проверка без сборки ролика

В Studio есть отдельные композиции карточки — прогоняй их после любой правки
`channel.ts` или этих файлов, не собирая ролик целиком.
