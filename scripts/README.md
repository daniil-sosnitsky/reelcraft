# scripts/ — рабочие скрипты конвейера

Запускаются из **корня проекта**, в bash (на Windows — Git Bash). Каждый
скрипт первой строкой подключает `tools/env.sh` — прослойку окружения, которая
собирает пути под текущую ОС. Путь к ней не зашит, а считается от самого
скрипта, поэтому проект переносится на любую машину как есть.

## Сборка ролика — основной маршрут

| Скрипт | Что делает |
|---|---|
| `../prep.sh` | Лежит в корне. Обработка звука записи: нормализация громкости и ускорение речи |
| `queue-add.sh` | Заводит слот ролика: кладёт звук, распознаёт речь пословно (whisper), готовит заготовку субтитров |
| `new-video.sh` | Создаёт каркас нового ролика в `engine/src/videos/` |
| `save-storyboard.sh` | Фиксирует сториборд в слот ролика |
| `lint-scenes.mjs` | Линт сцен: ловит нарушения норм конвейера до рендера — например случайность вне `mulberry32` (рендер многопоточный, `Math.random` даёт разные кадры в разных потоках). Полный список проверок — в самом скрипте |
| `qa-auto.sh` | Авто-QA: прогоняет проверки по собранному ролику |
| `qa-sheet.sh` | Контактный лист — кадры ролика сеткой, чтобы просмотреть постановку глазами за один взгляд |
| `render.sh` | Рендер и мастеринг звука на выходе |
| `clean-out.sh` | Чистка артефактов рендера в `out/` |

## Вокруг ролика

| Скрипт | Что делает |
|---|---|
| `fetch-icons.mjs` | Докачивает иконки брендов, которые звучат в речи |
| `footage-add.sh` | Кладёт запись экрана или съёмку в банк `footage/` и дописывает опись |
| `workbench.sh` | Монтажный стол: открывает собранный ролик для доводки без правки кода. Гасит старый dev server сам — лаунчер кита на Windows этого не умеет |
| `setup-assets.sh` | Доставляет звуковые эффекты из клона каталога приёмов. Вызывается установщиком |
| `sfx-catalog.sh`, `sfx-peaks.py` | Опись банка эффектов и замер пиков — чтобы эффект не перебивал речь |
| `audio-offset.py`, `rc_audio.py`, `transcribe.py` | Служебные: сдвиг дорожек, работа со звуком, вызов распознавания |
| `token-report.py` | Сколько токенов ушло на сборку — куда уходит бюджет |

## Карточки экрана — `screen-cards/`

Генератор «живого экрана» для кадров, где показать настоящий скриншот нельзя
или незачем: код, JSON, терминал, интерфейс. Собирает HTML по шаблону, снимает
его и отдаёт картинку для сцены. Своя подпись — `screen-cards/README.md`.

| Файл | Что делает |
|---|---|
| `make_code_html.py` | Вёрстка и подсветка: код, JSON, терминал |
| `build.py` | Общая сборка карточек по описанию |
| `build_anon.py` | То же, но с обезличиванием — когда в кадр не должны попасть свои пути и имена |
| `shoot_cards.py`, `measure.py` | Съёмка готовых карточек и замер, чтобы текст не выходил за кадр |
| `templates/` | HTML-шаблоны карточек |
| `build_video0*.py` | Сборки под конкретные ролики — образцы, а не универсальные скрипты |

## Разбор чужих роликов

Не для копирования: берётся только **форма** — темп, порядок сцен, устройство
хука. Текст и подача свои, иначе ролик считывается как пересказ.

| Скрипт | Что делает |
|---|---|
| `style-teardown.sh` | Разбирает ролик по ссылке: скачивает, режет на кадры, собирает плёнку |
| `style-grid.sh`, `style-inner.sh` | Контактные листы разбора: общий и покадровый внутри сцены |
| `style-transitions.sh` | Вытаскивает стыки сцен — на чём держатся переходы |

## Запись экрана (только Windows)

| Скрипт | Что делает |
|---|---|
| `rec-window.ps1` | Запись отдельного окна программы |
| `rec-shell.ps1` | Запись терминала |
| `rec-voice.ps1` | Запись голоса с микрофона |

PowerShell-скрипты, потому что захват окон и устройств — системная часть
Windows. На macOS и Linux запись делается средствами ОС.
