# character/ — персонаж светлой темы

Светлая тема ставит в низ кадра нарисованного персонажа, который «играет»
позами под речь. Персонажа в комплекте нет намеренно: это нарисованная
внешность конкретного человека, и отдавать её вместе с конвейером нельзя.

Здесь — что именно нужно нарисовать и по каким требованиям.

> Персонаж не обязателен. Тёмные темы его не используют вообще — если рисовать
> не хочешь, выбери тёмную тему по умолчанию (`library/adaptive-theme.md`), и
> эта папка останется пустой. Это полноценный путь, а не упрощение.

## Что нужно: десять файлов PNG с прозрачным фоном

Имена ровно такие — движок ищет по ним:

| Файл | Поза | Где используется |
|---|---|---|
| `pose-base.png` | спокойная стойка, руки опущены | дефолт, между акцентами |
| `pose-welcome.png` | открытые руки навстречу | приветствие, первый кадр |
| `pose-wave.png` | рука поднята в приветствии | прощание, финал |
| `pose-present-left.png` | рука указывает влево | контент слева в кадре |
| `pose-present-right.png` | рука указывает вправо | контент справа |
| `pose-think-chin.png` | рука у подбородка | вопрос, сомнение |
| `pose-think-cross.png` | руки сложены на груди | оценка, вывод |
| `pose-shrug.png` | плечи приподняты, ладони вверх | «а что поделать» |
| `pose-stop.png` | ладонь вперёд | запрет, предупреждение |
| `pose-fists.png` | кулаки сжаты | решимость, итог |

## Требования к файлам

- **Прозрачный фон.** Не белый: белый нельзя вырезать, не съев светлую одежду.
- **Одинаковый рост фигуры на всех позах.** Иначе персонаж «прыгает» при смене.
- **Фигура по центру**, целиком, без обрезанных кистей и ступней.
- **Размер около 1056×1140.**
- **Без теней на фоне** — тень рисует движок, своя в кадре будет двойной.

## Как получить

Сгенерировать в любой рисующей нейросети по одному описанию, меняя только позу
и руки — тогда персонаж получится одинаковым на всех десяти файлах:

```
персонаж в плоском рисованном стиле, ровный контур, спокойные цвета,
прозрачный фон, фигура целиком, поза: <нужная из таблицы>
```

### Если модель плохо отдаёт прозрачный фон

Рабочий обход: генерировать на сплошной магенте `#FF00FF`, затем вырезать её
в альфу. Магента выбрана потому, что её нет в коже, одежде и волосах, поэтому
край получается чистым. Скрипт для вырезания — `tools/character-cutout.py`.

### Проверь глазами все десять

Лишние руки и обрезанные кисти генерация выдаёт регулярно, а в кадре это
замечают сразу. Это пять минут, которые экономят переделку ролика.

## Смена поз в кадре

Переключать позы только через `<Character swapMode="dip">`, не `fade`:
на `fade` две позы на мгновение видны одновременно, и персонаж «двоится».
