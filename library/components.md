# Готовые компоненты shotcraft (assets/lib) — НЕ переписывать, копировать

Источник: `../video-shotcraft/skill/assets/lib/` (локальный клон, никуда
не денется). Правило shotcraft: компонент КОПИРУЕТСЯ в проект ролика в момент,
когда сториборд выбрал приём, стоящий на нём, и дальше правится свободно
(не импортировать из клона). Писать свой аналог с нуля = выбросить их
отладку — запрещено, сначала смотреть сюда.

ОБЯЗАТЕЛЬНО на сториборде: если сцена попадает в один из случаев ниже —
в паспорт задания Sonnet'у вписывается путь к компоненту.

| Компонент | Что делает | Когда брать |
|---|---|---|
| `PageCam.tsx` | 2.5D-камера по странице: полноэкранная текстура скриншота + наезды/панорамы ключевыми кадрами + оверлеи в координатах страницы; внутри — трюк CSS zoom для чёткости текста при наезде (их правило Q2) | ЛЮБОЙ пролёт/наезд по скриншоту сервиса или репо — фундамент всех «живых страниц» |
| `DigitRoll.tsx` | одометр: колонки цифр прокручиваются до значения (моноширинный шрифт) | большая цифра, счётчик, цена |
| `VerticalTicker.tsx` | 3D-стена бесконечной вертикальной прокрутки (items = любые ReactNode; маска, перспектива, скорость — пропсы) | поток карточек/строк/логотипов «их много» |
| `FlashCut.tsx` | тёпло-белый блум поверх жёсткой склейки | акцентная склейка сцен (только тема без персонажа; НЕ строб — одиночная вспышка склейки) |
| `Caption.tsx` | инфо-полоска низа кадра (моно, янтарный квадратик) | подпись-примечание; ⚠ дефолт 22px ниже нашего порога читаемости — поднимать размер (правило 13) |
| `FlatPanel.tsx` | панель в настоящем 3D (three) с контактной тенью | только если сториборд требует настоящий 3D-наклон; тянет three + @react-three/fiber + @remotion/three — без нужды не брать |
| `helpers/` (motion, rand, shake, camera) | изинги/качание/тряска/камера | уже портированы в `engine/src/lib/helpers.ts`; сверяться при расхождениях; `camera.tsx` (3D) — только вместе с FlatPanel |

Плюс: у отдельных карточек demo лежит в `template/src/aifl/` (путь указан в
записи карточки) — это тоже готовый код, копировать оттуда же.

## Наши компоненты языка emerald-velvet (`engine/src/lib/`)

**Это НЕ из каталога приёмов и НЕ копируются** — импортируются из `lib/`. Написаны под
тёмный язык emerald-velvet (принят 2026-11-07), паспорт языка со всеми
числами — `library/velvet-theme.md`. Копипаста в папку ролика запрещена: два
ролика разойдутся на второй правке.

| Компонент | Что делает | Когда брать |
|---|---|---|
| `velvet.tsx` | грамматика кадра языка: `Stage` (фон по тону плана), `CloseUp` + `camCy` (рисованная камера), `Panel`, `Tile` (с `fitText` внутри), `Pill`, `Wire`, `GenericIcon`, `BrandIcon`, тип `Rect` | **любой ролик на теме emerald-velvet** — точка входа |
| `motion.ts` | кривые `EASE`, роли движения `MOTION` (media/hero/support/meta/accent), `roleStyle()`, `stagger()`, `hold()` (микропуш на долгом холде), `snapBlur()`, `caret()` | вместо одного `spring` на все входы: разброс длительностей 4,25× |
| `cutPlan.ts` | `validateCutPlan(shots)` — арифметическая проверка «на границе плана меняются ≥2 величины из 3 (тон/масштаб/тип)». Бросает на уровне модуля | таблица планов любого ролика; склейка проверяется ДО рендера |
| `BackdropDepth.tsx` | слоистый фон: база → асимметричные пятна свечения → виньетка → зерно | тёмный фон; плоский градиент — признак дешёвого кадра |
| `Grain.tsx` | зерно `feTurbulence`, детерминированное, z-index 58 (над контентом, под караоке 60) | внутри `BackdropDepth`; отдельно — только поверх медиа |
| `AppFrame.tsx` | **нарисованное окно сервиса**: вкладка, фавикон бренда из банка, адресная строка или шапка чата с именем и статусом, курсор, поле ввода. Варианты `browser` / `chat`; плюс `ChatBubble` | когда нужен узнаваемый экран, а настоящий скрин нечитаем (правило 27, правка 2026-11-02). Настоящий экран остаётся источником цифр |
| `TypeStack.tsx` | типографика по шкале темы: `TypeStack` (строки с маркером-заливкой под словом), `Label` (капс Oswald), `stepFont()` | любой крупный заголовок; `stepFont` нужен и для расчётов `fitText` |
| `LightPlay.tsx` | свет: `cone` (конус выметает заголовок, строго линейно), `sheen` (блик 28–34 кадра, клипается в носитель), `halation` (гало ≤14 кадров, ≤40 % площади) | один акцент на героя кадра, не больше |
| `Fullbleed.tsx` | осознанное «во весь кадр» с пометкой, которую понимает линт, + автоскрим под полосой караоке | крупный план, выходящий за кромки (правило 26 — исключение только с пометкой) |
| `EdgeFrame.tsx` | хайрлайн шампанью по кромкам + угловая метка Oswald | ⚠ из принятого ролика снят по просьбе автора — ставить только по отдельной просьбе |
| `Broll.tsx` | живой план во весь кадр (см. CLAUDE.md, «Образец для кода») | когда в кадре настоящее видео, а не рисунок |
