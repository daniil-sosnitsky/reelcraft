# footage/ — свой банк живого видео

Пустая папка — так и должно быть. Сюда складывается **твоё** живое видео:
записи экрана, съёмка, пруфы. Чужой футаж в ролике бесполезен, поэтому в
комплекте его нет.

| Папка | Что сюда |
|---|---|
| `clips/` | записи экрана и съёмка, нарезанные под кадры |
| `proofs/` | пруфы: скрины результатов, цифр, интерфейсов |
| `_takes/` | сырые дубли до нарезки |

## Зачем это обязательно

Правило 27 требует **живого экрана** в кадре: в каждом ролике должен быть хотя
бы один настоящий скриншот или запись окна программы с наездом камеры. Без
этого ролик выглядит как набор титров, и это видно сразу.

Поэтому банк футажа — не опция. Снимай то, о чём говоришь, заранее: искать
картинку в момент вёрстки дорого, сцена уже собрана под то, чего нет.

## Как добавлять

```bash
scripts/footage-add.sh <файл>
```

Скрипт кладёт файл на место и дописывает строку в опись `catalog.md`. Опись
нужна, чтобы через месяц не пересматривать двадцать клипов в поисках нужного:
агент выбирает кадр по описанию из неё, а не по именам файлов.

## Запись экрана под Windows

В `scripts/` лежат три готовых скрипта: `rec-window.ps1` (отдельное окно
программы), `rec-shell.ps1` (терминал), `rec-voice.ps1` (голос с микрофона).
На macOS и Linux запись делается средствами системы.

## В git не уходит

Содержимое папки — личные записи и десятки мегабайт. В репозитории живут
только эта подпись и структура.
