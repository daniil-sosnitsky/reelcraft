# tools/ — прослойка окружения и инструментарий

Эта папка **не из базового комплекта**. Она появилась, когда конвейер ставили
нативно на Windows, и решает одну задачу: скрипты, написанные под macOS,
должны работать на любой ОС без правки в десятке мест.

## Что здесь

| Файл / папка | Что это |
|---|---|
| `env.sh` | **Единственная точка правки окружения.** Определяет ОС и собирает под неё пути, шрифт для QA и кодировку вывода. Подключается первой строкой каждого скрипта. Своё расположение вычисляет сам — абсолютных путей внутри нет намеренно, иначе проект не переносится |
| `restore-tools.ps1` | **Установщик инструментария под Windows.** Качает ffmpeg, whisper-cli с бэкендами, модель распознавания, каталог приёмов, ставит зависимости движка и звуковые банки. Идемпотентен: что стоит — пропускает, прерванный запуск можно повторить |
| `WINDOWS.md` | **Журнал решений:** почему слой устроен так, какие поломки чинились и что переналожить после обновления базового комплекта. Читать, когда что-то не сходится |
| `bin/` | Шимы — три крошечных скрипта, подменяющих отсутствующие на Windows утилиты |
| `character-cutout.py` | Вырезание персонажа из картинки по контуру — убирает фон генерации (подготовка своих поз) |
| `make-placeholder-poses.py` | Рисует нейтральные серые заглушки персонажа. Нужны, чтобы контрольный рендер светлой темы проходил до того, как ты нарисуешь своего |
| `ffmpeg/`, `whisper/`, `whisper-models/` | Скачанные бинарники и модель. **В git не уходят** — GitHub не принимает файлы больше 100 МБ, а здесь ffmpeg 217 МБ и модель 1,6 ГБ. Восстанавливаются `restore-tools.ps1` |

## Зачем шимы

| Шим | Что чинит |
|---|---|
| `head` | в минимальной сборке Git Bash утилиты `head` нет вообще, а скрипты её зовут |
| `python3` | в Windows-PATH `python3` — заглушка Microsoft Store: печатает «Python» и выходит. Настоящий интерпретатор зовётся `python` |
| `caffeinate` | macOS-утилита «не давать машине уснуть во время рендера». На Windows не нужна: съедает свои флаги и запускает команду как есть |

## Почему инструменты лежат внутри проекта

На `C:\` обычно нет прав записи, а системный PATH трогать незачем: конвейеру
нужны конкретные версии, и ломать ими остальную систему — плохая сделка.
Прослойка ставит `tools/` **в начало** PATH, а не в конец: нерабочую заглушку
`python3` нужно перекрыть, а не дополнить.

## На macOS и Linux

`env.sh` там почти ничего не делает — только подсказывает шрифт для подписей
на контактном листе QA. ffmpeg, whisper-cli, `python3` и `head` берутся из
системы. Папки с бинарниками не нужны, `restore-tools.ps1` не запускается.
