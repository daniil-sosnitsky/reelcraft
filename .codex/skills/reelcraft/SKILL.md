# Reelcraft в Codex

Этот навык управляет **существующим** конвейером. Перед работой прочитай `CLAUDE.md` и `.claude/skills/reelcraft/SKILL.md`: они остаются источником правил, порядка этапов и точных путей. Для конкретного этапа прочитай соответствующий `.claude/agents/reel-*.md`. Формат Claude (`tools:`, `model:`, названия инструментов) переводи на доступные инструменты Codex; содержательные требования и проверки сохраняй.

## Неизменные пути и совместимость

- Вход — `inbox/`; слот — `queue/video-NN/`; код — `engine/src/videos/video-NN/`; ассеты — `engine/public/videos/NN/`; временный рендер — `engine/out/`; окончательный MP4 — в `CHANNEL.outputDir` и его подпапках/датах из `engine/src/channel.ts`. Не придумывай параллельную структуру вывода.
- Используй существующие `prep.sh`, `scripts/queue-add.sh`, `scripts/new-video.sh`, `scripts/render.sh`, `scripts/qa-auto.sh`, `scripts/qa-sheet.sh` и остальные штатные проверки. На Windows запускай `.sh` через `C:/Program Files/Git/bin/bash.exe` и читай `tools/WINDOWS.md` при проблемах окружения.
- Не меняй `CLAUDE.md`, `.claude/`, общие Claude-инструкции и память, существующую инфраструктуру рендера, форматы слотов и пути вывода ради адаптации к Codex. Новые правила Codex живут только в `.codex/`.
- Для нового ролика создавай ровно те файлы, которые предусмотрены старым конвейером. Перед изменением общих файлов (`Root.tsx`, `library/used-log.md`) перечитывай актуальное состояние: возможны параллельные слоты.

## Ход работы

1. Найди запись или названный слот и определи следующий незавершённый этап по файлам. Один ролик — одна сессия; уже созданные результаты этапов не переделывай без причины.
2. В роли режиссёра используй модель проекта `gpt-6-astra` с уровнем рассуждения `high` для творческого ядра и сториборда. При доступном делегировании назначай этапы агентам `.codex/agents/`: `reel_transcript` (3), `reel_banks` (4а), `reel_footage` (4б), `reel_build` (6), `reel_qa` (7), `reel_wrap` (9–10). Этапы 3 и 4 могут идти параллельно; дождись результатов перед сторибордом. При недоступности выбранной модели или агента не подменяй их молча.
3. Выполни порядок из исходного навыка: подготовка звука → слот/Whisper → вычитка и банки/футаж → сториборд → сцены Remotion → линт/TypeScript/рендер/авто-QA → визуальный терчек → исправления/мастеринг/готовый MP4 → лог. Проверяй фактические результаты, а не только отчёты агентов.
4. Для публичного текста прочитай свои файлы голоса, бренда и позиционирования, как требует исходный навык. Реальные кадры и данные сверяй с источниками, не додумывай цифры.
5. После сдачи сохрани структуру оригинала. Чистку слота и черновиков проводи только после отдельного согласия автора, как указано в исходном навыке.

Если права текущей сессии не позволяют писать в `D:/AI/Ролики` или vault, запроси доступ для **исходного** места назначения. Не переноси финал в другую папку без согласования.
