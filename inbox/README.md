# inbox/ — вход конвейера

Сюда кладётся то, с чего начинается ролик: **запись голоса** и **скриншоты**,
которые должны попасть в кадр.

| Папка / файл | Что сюда |
|---|---|
| корень `inbox/` | записи голоса, готовые к обработке (`prep.sh`) |
| `_raw/` | сырьё как пришло с устройства — до нормализации |
| `_done/` | обработанные записи, уже заведённые в слот |
| `screenshots/` | скриншоты и записи экрана к конкретному ролику |

## Порядок

1. Запиши голос 40–60 секунд. Писать можно на что угодно, включая телефон —
   файл просто кладётся сюда.
2. `./prep.sh` — нормализует громкость и ускоряет речь, рядом появится файл
   с суффиксом `-prep`.
3. `scripts/queue-add.sh inbox/<имя>-prep.mp4 01` — заводит слот ролика
   с номером `01`, распознаёт речь пословно и готовит субтитры.

## Живой экран обязателен

В ролике должен быть хотя бы один настоящий скриншот или запись экрана с
наездом камеры — это правило конвейера, а не пожелание. Сними то, о чём
говоришь, **до** сборки и положи в `screenshots/` (или в `footage/clips/`,
если это видео, — плюс строка в `footage/catalog.md`). Искать картинки в
момент вёрстки дорого: сцена уже собрана под то, чего нет.

## Содержимое в git не уходит

Записи голоса и скриншоты — личные файлы и десятки мегабайт. В репозитории
живут только эта подпись и структура папок.
