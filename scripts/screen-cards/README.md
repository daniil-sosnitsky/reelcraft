# Карточки-скрины для роликов

Генераторы «живого экрана» там, где настоящий скриншот снять нельзя или
нельзя показывать: карточка кода, терминальный вывод, таблица прогона.
Собраны для video-02 («Радар конкурентов»), вынесены сюда 2026-10-10, чтобы
при следующем прогоне радара карточки пересобирались командой, а не руками.

## Зачем это вообще

Прошлый скрин `accounts.json` оказался **подделкой**: в нём стояли
комментарии `//` внутри JSON (в JSON такого синтаксиса нет) и сдвинутые
номера строк. На экране это выглядит убедительно, а по факту — выдуманная
фактура, что прямо запрещено голосом канала.

Поэтому правило простое: **карточка всегда рендерится из настоящего файла**,
а не пишется руками «похоже на правду». Содержимое и нумерация строк берутся
из исходника как есть.

## Файлы

| Файл | Что делает |
|---|---|
| `make_code_html.py` | движок: HTML-карточка кода из РЕАЛЬНОГО файла — окно редактора, подсветка, настоящие номера строк |
| `build.py` | собирает карточки `06-criteria` (фрагмент `accounts.json`) и `07-runsh` (фрагмент `run.sh`) |
| `build_anon.py` | обезличенные пересборки таблиц: хендлы доноров → «Аккаунт N», колонка ссылок убрана. **Все числа берутся из настоящих файлов и не трогаются** |
| `measure.py` | замер целей наезда **пипеткой**: ищет плотный bbox чернил внутри грубой области. Это и есть «замерить в ассете, а не на глаз» из правила 28 |
| `templates/` | HTML-заготовки карточек |
| `final_targets.json` | замеренные цели наездов video-02 — образец формата |

## Как пользоваться

```bash
# пересобрать карточки кода (после изменения radar/accounts.json или run.sh)
python scripts/screen-cards/build.py

# пересобрать обезличенные таблицы (после нового прогона радара)
python scripts/screen-cards/build_anon.py
```

HTML превращается в PNG скриншотом headless-браузера; ширина карточки —
1200 px, под неё посчитаны все цели наездов.

## `measure.py` — главная ценность этой папки

Он нужен **любому ролику**, не только про радар. Правило 28 требует мерить
цель наезда в самом ассете, а не на глаз: рамка не должна резать строку или
прихватывать соседний абзац. `measure.py` делает это арифметикой — берёт
грубую область, определяет фон как самый частый цвет и стягивает bbox по
пикселям, отличающимся от фона.

Пока разведка меряла цели вручную, это был самый долгий шаг конвейера.

## Обезличивание

`build_anon.py` держит порядок аккаунтов таким же, как в реальной базе
`radar/out/shortlist.md` — то есть «Аккаунт 3» всегда один и тот же аккаунт
от прогона к прогону, пока база не поменялась.

Решение убирать хендлы — не про приватность (публичный хендл под стоп-лист
не подпадает), а про позиционирование: ролик про свою систему, а не про
«вот кого я парсю».
