| Файл | Что изучать | Что адаптировать перед применением |
|---|---|---|
| `src/components/flip-page-transition/FlipPageTransition.tsx` | Угол страницы и отбрасываемая тень используют общий прогресс; явный размер вращаемого слоя | Поворот к смысловому моменту речи; фон и 1080×1920, локальный шрифт |
| `src/components/text-mask-reveal/TextMaskReveal.tsx` | Закрывающая и раскрывающая фазы движущейся маски, последовательность строк | Длина русских строк, непрерывно читаемая обложка, зона караоке |
| `src/components/split-screen/SplitScreen.tsx` | Раздельные clip-path половин и движущийся разделитель | Две равноправные стороны без автоматического «плохо/хорошо», безопасные поля |
| `src/components/parallax-pan/ParallaxPan.tsx` | Разная скорость дальнего/среднего/переднего слоя | Использовать для смыслового движения камеры, а не вечного фонового движения |
| `src/components/thinking-bubble/ThinkingBubble.tsx` | Наклон головы, последовательная цепочка к главному облачку | Отключить ненужный бесконечный цикл; персонаж только если он выбран для темы |

Исходники просмотрены как рецепты; локально не рендерились и не импортированы в video13. В engine зависимости не добавлялись. Перед использованием: заменить системные шрифты локальными, численные тайминги связать с речью, сохранить уведомления MIT, пройти обычные TypeScript/lint/визуальные проверки проекта. Не копировать целый шаблон без адаптации композиции.
